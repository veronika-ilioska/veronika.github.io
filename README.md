# Personal Autobiography Website

A simple multi-page personal website created with **HTML** and **CSS**.

## Live Website

[View the website on GitHub Pages](https://veronika-ilioska.github.io/veronika.github.io/)

## About the Project

This project is a static personal website designed as an online autobiography. It demonstrates the use of fundamental web development concepts such as:

- Semantic HTML structure
- Multi-page website navigation
- Custom CSS styling
- Images and visual content
- Tables, lists, links, and forms
- GitHub Pages deployment


## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## Running the Project Locally

No installation or build process is required.

1. Clone the repository:

```bash
git clone https://github.com/veronika-ilioska/veronika.github.io.git
```

2. Open the project directory:

```bash
cd veronika.github.io
```

3. Open `index.html` in a web browser.

You can also run the project with the **Live Server** extension in Visual Studio Code:

1. Open the repository in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
